1. 接続して起動する

  1. C922nをAcerのUSBへ、XiaomiをHDMIへ接続。Windowsのディスプレイ設定を「拡張」にします。Acerを主画面・操作用、Xiaomiを観客用にします。
  2. エクスプローラーで次のフォルダーを開きます。

    C:\Users\go\Documents\ChatGPT\New project

  3. Start Rebirth Production.cmd をダブルクリックします。旧「Start Rebirth Acer.cmd」は単一シーン用なので、今回はこちらを使います。
  4. ブラウザーに「オペレーター」が出るまで待ちます。起動確認は最大90秒。Xiaomiにシーンが現れ、UIに「接続中」「表示中」が出たら準備完了です。開始時の小さなターミナルは正常起動後に閉じます。

接続と画面配置は先に人が整えます。起動ファイルはWindows設定やカメラ設定を自動で書き換えません。内部の観客画面名は現在 DISPLAY5 です。Windowsでいう「2枚目」と番号が一致する必要はありません。

2. UIを開く・見分ける

操作UIはAcer上のブラウザーで見ます。見失ったら、同じ Start Rebirth Production.cmd をもう一度ダブルクリックしてください。稼働中のManagerを見つけた場合は、もう一台起動せず、その操作パネルを開き直します。

ブラウザーがXiaomiに出た場合は、ブラウザーを選んで Windowsキー＋Shift＋左矢印 でAcer側へ移動します（現在はXiaomiが右側の配置）。実行中にUIだけ閉じても、Managerは継続します。

「現在」が狙ったシーン名、「表示中」が出ていることを確認。「受付済み」は指示を受け取った状態です。Xiaomiの映像が切り替わるまで連打しないでください。

3. シーンを操作する

UIの表示何をするか確認すること
シーン一覧名前をクリックして直接切替「現在」とXiaomiが同じシーンになる
Next / Back次／前のシーンへ切替ブロックのトランジション後に映像が戻る
Restart現在のシーンを起動し直す同じシーンの映像と反応が戻る

UIはクリックで操作します。観客画面のNext／Backは指を約1秒置く方式で、虹色の外周ゲージが一周すると切替。途中で指を外すとキャンセルです。

4. 映像を調整する

項目操作見方
カメラ映像の濃さスライダーを動かして離す0%で隠す、100%で通常表示。検出には影響しない
露出数値またはスライダーで変更値を大きくすると明るくなる。残像と反応速度も見る
ズーム数値またはスライダーで変更手首や体が見切れない画角にする
  1. 露出・ズームは、変える項目だけ「この値を適用する」をチェック。
  2. 「映像に適用」をクリックし、Xiaomiの映像とUIの「実際の値」を確認します。
  3. 次回起動にも残す場合だけ「適用済みの値をJSON保存」。これは設定ファイルを書き換える操作です。凍結時の設定を維持したい間は保存しません。

映像の濃さはシーン切替後も維持されますが、Manager再起動で100%へ戻ります。黒背景仕様のSkeletonなど、生映像を使わないシーンもあります。明るさを比較するなら生映像が出るシーンで確認してください。

5. 現場での短い確認

チェックはこのページ内だけの一時メモです。試験結果の記録には保存されません。子供自身の試験と実際の複数人試験は、現場で別に実施・記録します。

6. 待機と終了を使い分ける

少し隠したい：「Safe · 演出遮蔽」。再開は「Safe解除」。Safeは黒一色ではなく、ロゴなどを含む演出で覆って待機します。

完全に終了する：下までスクロールして「Managerを終了」をクリックし、確認に答えます。終了後はXiaomiにWindowsデスクトップが見えるため、観客に見せたくない間はSafeを使います。

7. 困ったとき

UIを閉じてしまった／どこにあるか分からない

「Start Rebirth Production.cmd」を再度ダブルクリック。既存の操作パネルを開きます。起動途中の場合は、先の起動が終わるまで待ちます。

「未接続」や認証エラーが出る

古いブックマークではなく、起動ファイルから開き直します。操作URLには起動ごとに変わる認証文字列が必要です。単に http://127.0.0.1:8766/ を手入力したり、operator_panel.html を直接開くだけでは操作できません。

ダブルクリックしても起動しない

エラーで残ったターミナルの内容を確認。検証済みPythonがない、画面が「複製」になっている、Xiaomiの内部名が変わった等の場合は起動前チェックで止まります。ソフトを何度も起動せず、表示された原因を記録してください。

カメラが映らない／手を見失う

C922nの接続、照明、手首まで映っているかを確認します。OBSなど他のカメラ使用アプリを避けます。「カメラオン」通知だけで復帰成功と判断せず、生映像と手への反応を見ます。Restartはシーンの再起動であり、物理カメラの復旧を保証するボタンではありません。

起動が90秒を超えた／ポート使用中と出る

起動中のプロセスは勝手に終了しません。パネルやログを確認し、重複起動を避けてください。ログはプロジェクト内の test_reports/production_launcher_*.stdout.log と *.stderr.log です。

製品基準は 2a6a116。既存シーン・Manager・Transition・設定は変更していません。今回の起動入口は追加の補助ファイルです。

起動前チェックと起動済みパネルの再利用を確認：CMD経由で17シーン、Python依存、Acer／Xiaomiの配置を検査しました。起動補助8件と関連オペレーター20件のテストも成功。実機で既存パネルへ認証でき、二重起動しないことを確認しました。停止状態からのダブルクリック実起動とブラウザーの実表示位置は未確認です。現場前に一度確認してください。
