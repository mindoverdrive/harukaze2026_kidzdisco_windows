# 操作モック

`mandala-time-evolution.html` をブラウザで直接開きます。依存ファイル・ビルド・通信・カメラ接続はありません。本番 Python は変更していません。

- 左は描画済み線を固定し、右は同じ作品をゆっくり回転・微小変形します。どちらにもマウス／タッチで描けます。
- 時間変化の ON/OFF は速度をなめらかに変えます。OFF で元の形へ戻さず、再開時もリセットしません。「模様を少し足す」は追記です。
- `finger_mandala_3.py` の `draw_mandala` と同じ 12 回転＋左右鏡像の座標式、および新規描線の軸角速度 0.035 rad/s を使用します。既存作品全体の回転・呼吸・微小な縦横伸縮は、このモックの提案です。
- 描線は固定サイズ 1024×1024 の画布へ蓄積します。過去の入力点は保存せず、表示時に画布を変換するため、線が増えても再描画の呼び出し数は増えません。原画は再サンプリングせず保持し、表示面のみ描き直します。
- 枠内の薄い円を描画範囲とし、外へ出た後の再入場・指を離した後の描画を長線で接続しません。タブ非表示中の経過時間も一度に進めません。
- マウス／タッチ入力の試作であり、カメラ認識・参加者判定・本番描画性能の再現ではありません。OS の動きを減らす設定では初期状態を OFF にします。

確認用に `window.mandalaMock.diagnostics()` から画布サイズ・線の追加数・平均描画時間を参照できます。描画時間はブラウザでの JavaScript 計測であり、本番アプリの FPS を意味しません。

検証：現行 Python の対称描画関数と 100 入力・4,800 座標値を照合し、最大差は約 2.22e-16。Node の DOM/Canvas モックで原画保持、停止・再開、描画入力、離脱・再入場・キャンセル、追記、固定画布、逆座標変換、タブ復帰時の連続性を確認しました。ブラウザの実描画・タッチ実機・見た目の好み・描画負荷は人による確認が必要です。
